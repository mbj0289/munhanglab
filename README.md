# 문항랩 — 수능 기출 분석 노트

PDF의 문항 영역을 직접 선택해 A4 세로형 분석 노트를 만드는 설치형 웹앱(PWA)입니다.

## GitHub Pages로 배포하기
1. GitHub에서 새 공개 저장소를 만듭니다(예: `munhanglab`).
2. 이 폴더 안의 파일 전체를 저장소 최상위(root)에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` 브랜치의 `/ (root)`를 지정한 뒤 저장합니다.
5. 배포가 완료되면 `https://사용자아이디.github.io/저장소이름/` 주소로 접속합니다.
6. 스마트폰 브라우저에서 접속해 설치합니다.
   - Android/Chrome: 메뉴(⋮) → 앱 설치 또는 홈 화면에 추가
   - iPhone/Safari: 공유 → 홈 화면에 추가

## 사용
- PDF 불러오기 → 페이지에서 문항을 드래그 선택 → 선택 문항 만들기
- 문항 목록에서 출력할 항목을 체크 → 미리보기 → PDF로 저장/인쇄
- 노트는 A4 세로형이며 왼쪽 열은 문항 1/3 + 분석 2/3, 오른쪽은 풀이 공간입니다.

## 참고
- 앱 화면과 기본 파일은 서비스 워커로 캐시됩니다.
- PDF 렌더링 라이브러리(PDF.js)는 CDN에서 불러오므로 PDF 기능을 처음 사용할 때 인터넷 연결이 필요합니다.
- GitHub Pages 배포는 사용자의 GitHub 계정에서 저장소를 생성하고 파일을 업로드해야 합니다. 이 패키지에서 계정에 직접 게시하지는 않습니다.


## 정답 및 해설 PDF 추가
메인 화면의 정답 및 해설 PDF 추가에서 별도 파일을 선택하면, 출력 노트의 문항 분석 페이지 뒤에 해설 PDF 전체 페이지가 원본 그대로 이어집니다. 해설 PDF는 문항별로 자르거나 재배치하지 않습니다.


## 분석 노트 레이아웃 업데이트
- 풀이 공간의 필기 줄 간격을 넓혔습니다.
- 분석 영역을 두 개의 가로 전체 폭 칸으로 구성했습니다: '주요 개념', '풀이 전략 및 핵심 아이디어'.
- 분석 영역의 필기 줄 간격은 풀이 공간과 동일하게 맞췄습니다.
