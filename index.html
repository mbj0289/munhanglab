01기출 PDF 불러오기

선택 안 됨

정답 및 해설 PDF는 문항별로 자르지 않고 원본 페이지 그대로 분석 노트 마지막에 이어 붙입니다.

각 페이지를 직접 확인하고 문항 영역을 드래그해 선택합니다. 자동 문항 인식은 사용하지 않습니다. 스마트폰에서는 화면을 길게 누른 뒤 드래그해 영역을 지정할 수 있습니다.

02인터넷 기출문제 자료실

EBSi 고3 기출문제 자료실 열기 ↗ EBS 교사지원센터 ↗ 수능 공식 홈페이지 ↗

EBSi는 2006학년도 이후 수능·모의평가·학력평가 기출 자료를 연도·학년·과목별로 제공한다고 안내하고 있습니다. 자료실에서 PDF 또는 제공 파일을 내려받은 뒤 위의 PDF 불러오기로 가져오세요. 일부 자료는 로그인 또는 교사 인증이 필요할 수 있습니다.

03페이지에서 문항 영역 직접 선택

/ 0

PDF 페이지에서 문항 번호와 지문·그림이 포함되도록 사각형을 드래그해 선택하세요. 선택한 영역은 분석 노트 왼쪽 위 문제 칸에 배치됩니다.

영역 미선택

04미리보기 및 PDF 출력

A4 세로형에서 왼쪽은 위쪽 문항(1/3)과 아래쪽 분석(2/3), 오른쪽은 풀이 공간으로 구성됩니다. 정답 및 해설 PDF를 추가하면 문항 노트 뒤에 원본 페이지가 이어집니다. PDF 저장 버튼을 누른 뒤 인쇄 창에서 'PDF로 저장'을 선택하세요.

분석 노트 미리보기
각 페이지에서 직접 지정한 영역만 문항 이미지로 사용합니다. 선택 영역에 문항 번호와 지문이 모두 들어갔는지 미리보기에서 확인하세요.
